Exam & Viva Defense Q&A

Q1: Why choose a 2D Array for class schedules instead of a linked list?

Answer: College timetables have fixed days and periods (e.g. 5 days × 5 slots). A 2D array gives immediate \(O(1)\) index lookup (timetable[day][period]) to verify slot occupancy without traversing elements.

Q2: How is the Priority Queue implemented for Events?

Answer: It is implemented via a sorted linked list using a composite timestamp key (\(Year \times 10000 + Month \times 100 + Day\)). Incoming events are inserted in ascending chronological order (\(O(K)\) insertion), making the head element always the earliest upcoming event (\(O(1)\)).

Q3: How does the system handle teacher conflict detection?

Answer: Before booking, the algorithm inspects if timetable[day][period].isBooked == true, and verifies if the assigned teacherId is already occupied in that exact time slot.
